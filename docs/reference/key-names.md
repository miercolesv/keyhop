# Key names

The names `keyhop keys` prints and the config accepts (case-insensitive).
Use them in [hotkeys](/features/hotkeys), [snap-click pairs](/features/keyboard-settings#snap-click-socd) and [key remapping](/features/keyboard-settings#remapping-single-keys).

## Letters

`a` `b` `c` `d` `e` `f` `g` `h` `i` `j` `k` `l` `m` `n` `o` `p` `q` `r` `s` `t` `u` `v` `w` `x` `y` `z`

## Digits

`1` `2` `3` `4` `5` `6` `7` `8` `9` `0`

## Function keys

`f1` `f2` `f3` `f4` `f5` `f6` `f7` `f8` `f9` `f10` `f11` `f12` `f13` `f14` `f15` `f16` `f17` `f18` `f19` `f20` `f21` `f22` `f23` `f24`

## Keypad

`numlock` `kp_divide` `kp_multiply` `kp_minus` `kp_plus` `kp_enter` `kp_1` `kp_2` `kp_3` `kp_4` `kp_5` `kp_6` `kp_7` `kp_8` `kp_9` `kp_0` `kp_period` `kp_equal` `kp_comma`

## Modifiers

`lctrl` `lshift` `lalt` `lmeta` `rctrl` `rshift` `ralt` `rmeta`

## Modifiers in hotkeys

In a [hotkey](/features/hotkeys#syntax), write modifiers as `ctrl`, `shift`, `alt` (`option`) and `meta` (`cmd`, `win`, `super`); they match either side.
